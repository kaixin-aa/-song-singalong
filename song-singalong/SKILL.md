# 英语歌曲跟唱音译

按用户指定范围制作可复制文本。首次制作或修改读法时读取[英语跟唱音译与发音规则](references/english-phonetics.md)。

## 核对输入与读法依据

- 使用用户提供或明确指定的歌词正文。只有歌名、歌手或不可读的素材时，请用户补充要做的歌词或片段。记录已有的录音版本和口音信息。
- 保留英文原文的行序、重复、拼写、大小写、标点、缩写与段落标题。疑似错词在成稿外指出，未经用户确认沿用原文。歌词中的重复指示按原样保留。
- 按已听辨的目标演唱标注发音。用户明确说明的唱法可据此调整，并注明依据。未听辨的部分使用用户指定的口音，未指定时采用常见美式发音。正文外标明“文字推导稿”或具体未核对的范围。仅将实际听辨过的部分标为“已核验”，并注明录音版本。

## 编写与检查

1. 每行英文配一行中文译文和一行跟唱音译。译文按上下文表达本行意思。用户要求歌词拆行时，在合适的乐句或词组边界断开，译文和音译同步分行。
2. 先判断整句唱出来的声音，再用常见汉字、易读的字母拼法和容易跟读的英文写出音译。空格按声音分组，允许把多个词写成一组，也允许按发音把长词分开。发音和节奏优先于字形整齐。
3. 顺着音译读完整句，检查主要元音、尾音、连读、音节数和节奏。核对原文、译文和音译逐句对应。相同唱法复用写法，有依据的差异按出现位置处理。
4. 试做先交短段落。用户给出明确范围时直接完成该范围。局部修改时只调整目标行及受影响的位置。

## 交付格式

成稿放在一个可复制的文本块内。每句固定三行，依次为英文原句、中文译文、跟唱音译。组间空一行，保留原有主歌、副歌等段落标题。需要解释难音时可在文本块外补 IPA 或简短提示。核验状态也放在文本块外。用户明确要求 IPA 时按要求交付。

```text
[英文原句]
[中文译文]
[跟唱音译]

[英文原句]
[中文译文]
[跟唱音译]
```
